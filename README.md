# Employee Management System

## Project Overview

The **Employee Management System** is a web application developed using **Java Full Stack technologies**.
This project allows users to manage employee records by performing basic **CRUD operations** such as adding, viewing, updating, and deleting employee details.

The system follows the **MVC (Model-View-Controller) architecture**, which separates the application logic, user interface, and data management.

---

## Features

* Add new employee details
* View all employee records
* Update employee information
* Delete employee records
* Simple and user-friendly interface

---

## Technologies Used

* **Java**
* **Spring MVC**
* **Hibernate / JPA**
* **JSP**
* **HTML**
* **CSS**
* **MySQL**
* **Apache Tomcat**

---

## Project Architecture

This project follows the **MVC architecture**:

* **Model:** Handles the business logic and database operations.
* **View:** JSP pages used for displaying data to the user.
* **Controller:** Handles user requests and connects Model and View.

---

## Tools Used

---

## How to Run the Project

1. Clone the repository from GitHub.
2. Import the project into **Eclipse IDE**.
3. Configure **Apache Tomcat Server**.
4. Connect the project to **MySQL Database**.
5. Run the project on the server.
